# 专辑能力扩展 — 实现方案（定稿 v2）
> 包含两件事：**A. 收藏的专辑**（资料库专辑置顶 + 全部专辑折叠）、**B. 未入库专辑可直接播放 + 详情页加号**。
> 两者共用同一块地基：**从 Apple 拉取某张专辑的曲目列表**。

## A. 收藏的专辑（用户已拍板）
1. 专辑页顶部 = 「收藏的专辑」**两列网格**（`/v1/me/library/albums`）；
2. 下方 = 「**全部专辑 (N)**」整行标题 + 箭头，**默认折叠、每次进入回到折叠**；
3. **去重**：已在收藏里的从"全部专辑"移除；
4. **点开收藏专辑**：本地有曲目 → 现有详情；本地没有 → **自动加载同步**（拉曲目入库）；
5. 收藏为空 → 整块隐藏。

## B. 未入库专辑：可直接播放 + 详情页加号（本轮新增，用户要求）
### 现状问题
从艺人详情页 / 搜索点开一张**未加入资料库**的专辑时，必须先"加入资料库"才能听。

### 目标行为
- **可以直接听**：点播放即播放整张专辑（无需先入库）；
- **专辑详情页按钮区**（右下角一带）：
  | 专辑状态 | 显示按钮 |
  |---|---|
  | **未入库** | 播放按钮（已有）+ 收藏/喜欢（已有）+ **加号「添加到资料库」**（新增）|
  | **已入库** | 播放按钮 + 收藏/喜欢（**不显示加号**）|

### 判定"是否已入库"
用已同步的 `apple_library_albums` 表按 **catalogId**（或名称+艺人）匹配；同步后该表为准。

### 曲目来源与播放
- 未入库专辑：`GET /v1/catalog/{storefront}/albums/{id}/tracks?limit=100&offset=N`
  （入库后切到 `/v1/me/library/albums/{id}/tracks`）；
- 这些曲目**以"临时专辑队列"进入播放器**（不写入 `songs` 表 ⇒ 不污染「全部歌曲」）；
- 首次播放仍需走现有 DRM 链路（webPlayback → license → 分段下载解密），会有几秒准备；
- **点到"加号"加入资料库成功后**：触发一次同步 ⇒ 该专辑进入「收藏的专辑」、加号消失、其曲目进入「全部歌曲」。

### 加号 = 写操作（需要你知情）
- 调用 Apple 的"加入资料库"接口（`POST /v1/me/library?ids[albums]=...`）；
- 这是**对你自己的资料库的写操作**（个人自用、用户主动点击触发），与之前"自动补齐空壳艺人"被撤掉的那次不同：**这次只有你点加号才会执行**，且会给 Toast 反馈（"已添加到资料库"）；
- 不做任何批量/自动写操作。

## 改动清单（在两件事之间共享）
| 文件 | 改动 |
|---|---|
| `apple/AppleApi.ets` | `getLibraryAlbums()`；`getAlbumTracks(catalogId?, libraryId?)`（catalog/library 双通道）；`addAlbumToLibrary(catalogId)`（写）；`isAlbumInLibrary(catalogId)` 可由 DB 查 |
| `db/MusicDatabase.ets` | 新表 `apple_library_albums`；新表 `apple_album_tracks`（临时/收藏专辑曲目，独立于 songs）；schema +1 |
| `apple/AppleLibrarySync.ets` | `syncLibraryAlbums()` 并入启动同步链 |
| `features/library/.../AlbumsPage.ets` | 收藏网格 + 「全部专辑 (N)」折叠行 + 去重 |
| `features/library/.../AlbumDetailPage.ets`（或对应详情实现） | 按钮区按"是否入库"条件显示加号；加号 → 调写接口 → Toast → 触发同步；未入库专辑的曲目列表从 catalog 拉取 |

## 验证
1. 日志：`library albums = N`；
2. dump/截图：收藏网格、折叠行、以及**未入库专辑详情页出现三个按钮**（播放/喜欢/加号）、入库专辑只有两个；
3. 未入库专辑点播放：能正常出声（首次下载准备几秒）；
4. 点加号：Toast 提示 + 该专辑出现在「收藏的专辑」+ 加号消失 + 曲目进入「全部歌曲」。
