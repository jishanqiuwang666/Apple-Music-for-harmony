# 板块与代码结构（二次开发地图）

这份文档的目标只有一个：**让你在 5 分钟内知道「某个界面在哪、数据从哪来、想改该动哪个文件」**。

界面按「板块」切开，代码按「三层 HAR」切开，两者一一对得上：

```
products/default        外壳：底部页签 + 每个 tab 一条导航栈 + 背景流光 + 播放层浮在最上面
      ↓ 只用下面两层
features/library        五个板块的页面（艺人 / 专辑 / 歌曲 / 歌单 / 搜索）+ 登录页 + 设置抽屉
features/player         播放条、全屏播放页、歌词视图
      ↓ 只用最下一层
common/musicbasic       能力层：Apple API、Widevine 解密、RDB、全局状态、工具
```

依赖方向是单向的（`products → features → common`）。**页面不直接读数据库，也不直接碰 AVPlayer**：
数据走 `musicbasic` 的内存镜像 / 数据库接口，播放走 `PlaybackHelper` / `MediaService`。

## 一、五大板块（界面维度）

| 板块 | 首页 | 详情页 | 数据来源 | 备注 |
|---|---|---|---|---|
| 艺人 | `features/library/.../view/ArtistsPage.ets` | `ArtistDetailPage.ets` | `/v1/me/library/artists` + `songs` 聚合 | 顶部「收藏的艺人」横排（`?extend=inFavorites`），长按拖动排序；下面按流派分组 |
| 专辑 | `AlbumsPage.ets` | `AlbumDetailPage.ets` | `/v1/me/library/albums` | 收藏专辑置顶并去重；**未入库专辑也能听**，曲目走目录接口临时队列 |
| 歌曲 | `AllSongsPage.ets` | — | `songs` 表（`is_library = 1`） | 大列表，行组件是 `SongListItem.ets` |
| 歌单 | `PlaylistsPage.ets` | `PlaylistDetailPage.ets` | `/v1/me/library/playlists` + 按需拉曲目 | 曲目落 `songs`（`folder = 'apple_playlist'`）；自动歌单（如「喜爱歌曲」）拿不到曲目是 Apple 侧限制 |
| 搜索 | `SearchPage.ets` | 复用上面三个详情页 | 本机内存镜像 + 目录 API | 只搜本地资料库；点开条目会**切 tab 再 push**（不是推到自己栈上） |

外壳里另有：`AppleLoginView.ets`（登录，走 Apple 官方页面）、`LibrarySearchOverlay.ets`（外壳上的统一搜索浮层）、
`products/default/.../view/SettingsDrawer.ets`（设置抽屉）。

### 板块之间共享的三样东西

1. **行/卡片组件**：`SongListItem`（歌曲行）、`HeroArtwork`（带共享元素转场的封面）、各页内部的卡片 Builder。
2. **跳转工具**：`features/library/.../util/HeroTransition.ets`（共享元素 id 命名与作用域）、`PlaybackHelper.ets`（唯一播放入口）、
   `HomeBack.ets`（首页接管返回键）。
3. **全局状态**：`MusicAppState`（当前曲目、播放态、抽屉开关等）、`LibrarySignal`（资料库变更通知）。

## 二、播放层（不属于任何 tab，浮在整个 App 上）

| 位置 | 文件 | 说明 |
|---|---|---|
| 底部播放条（折叠 / 展开） | `features/player/.../view/Player.ets` | 住在 HDS 悬浮页签栏的 `miniBar` 里，展开由 `applyMiniBarStyle` 驱动 |
| 全屏播放页 | `PhonePlaybackPage.ets` | 封面「生长」动画：与播放条那颗封面是同一个几何插值节点 |
| 歌词页 | `AppleLyricsView.ets` + `model/LyricVisual.ets` + `model/LyricPlayhead.ets` | 逐字填充、`translateY` 自持滚动、景深压暗 |
| 播放核心 | `model/MediaService.ets` | 应用级单例：AVPlayer + 音频焦点 + AVSession + 后台任务，页面销毁不打断播放 |
| 音量 | `model/SystemVolume.ets` + `view/VolumeSlider.ets` | 唯一真源是系统媒体音量，应用自己不改系统音量 |
| 播放入口 | `features/library/.../util/PlaybackHelper.ets` | 所有列表点击最终都汇到这里，队列与浏览列表分离 |

**三条纪律**（改了会立刻出 bug）：

- 播放位置的唯一来源是 `MediaService.playheadMs()`（读 `avPlayer.currentTime`），**不要用进度 + 墙钟插值**；
- 播放器是应用级单例，页面 `aboutToDisappear` 不要 release；
- 换歌收敛成唯一入口，回调里判断「事件是否来自当前实例」。

## 四、外壳（`products/default/src/main/ets/pages/Index.ets`）

一个 `Stack()` 里叠了这些层（从下到上）：

1. **背景流光**：整个 App 只有一层 `UV_BACKGROUND_FLOW_LIGHT`，放在 `HdsTabs` **外面** —— 切 tab 时背景不动；
2. **`HdsTabs`**：5 个 `TabContent`（艺人 0 / 专辑 1 / 歌曲 2 / 歌单 3 / 搜索 4），底部悬浮页签栏 + `miniBar` 里的播放条；
   **每个 tab 一条独立的 `NavPathStack`**（`@Provider` 注入，页面里 `@Consumer` 取）；
3. **悬浮工具层**：左上同步 / 右上搜索 / 抽屉热区（透明触摸层，按起手点分流）；
4. **播放页与歌词**：`FullPlayerSheet`（`zIndex` 高于 `HdsTabs`，因为 HDS 自带 `zIndex(1)`）；
5. **登录层**：未登录时覆盖全屏。

路由表：`features/library/src/main/resources/base/profile/router_map.json`（7 个路由：
`ArtistHome` / `ArtistDetail` / `AlbumHome` / `AlbumDetail` / `PlaylistHome` / `PlaylistDetail` / `SearchHome`）。
**新增页面必须在这里注册**，否则 `pushPathByName` 找不到。

## 六、踩过的坑（改之前先读，能省几小时）

**导航与转场**

- 每个 tab 一条栈；页面内所有 `push`/`pop` 必须走 `activeStack()`，并把「来源标记」（如 `fromSearch`）**透传给下一级**，
  否则会出现「弹错栈 → 内容消失但页面还在」。
- 共享元素转场**只在两个 `NavDestination` 之间**生效：列表首页也得是 `NavDestination`；
  `geometryTransition` 的 id 必须全局唯一，按作用域加前缀（`search-tab` / `artist-detail-album` …）。
- 首页 `NavDestination` 必须接管 `onBackPressed`（否则返回把首页弹掉 → 只剩背景色）。

**列表与状态**

- `Scroll` 里套 `Grid`/`List` 会让 `LazyForEach` **退化成全量构建**（一屏几百个卡片 = 首建 1~2 秒 + 掉帧）。
  要虚拟化就让 `Grid`/`List` 自己当滚动容器。
- `ForEach` 的 key 若不含「结构代数」，子组件会一直持有旧对象，之后所有 `@Trace` 写入都不上屏。
- `Scroll` 内容比视口短时会**垂直居中**，要贴顶必须 `constraintSize({ minHeight: '100%' })`。
- 固定高度的 `Grid` 喂全量数据前先算总高度，否则下方控件被顶到几屏之外、用户根本翻不到。

**手势**

- ArkUI 的触摸/手势坐标单位是 **vp**，不要再 `px2vp()`（多除一次 3.25，表现为「跟手只有 1/3」）。
- 整屏 `priorityGesture` 会吃掉页内所有同方向拖动；需要「长按再拖」时直接用 `onTouch` 自己做状态机最稳。
- `Image.draggable` 自 API 11 起默认 `true`，会抢走长按 —— 卡片里的封面要显式 `.draggable(false)`。

**播放与解密**

- 解密后**必须删掉 `moov` 里的 `pssh`**，否则 AVPlayer 会等一个永远不来的许可证（`prepare()` 永不完成）。
- 并发下载同一首要用 single-flight + 原子写（`.part` → rename），否则半截文件被登记进缓存 → 那首歌永久播不出来。
- 逐 sample 解密要复用 `symKey` 与 cipher 对象池（实测 13.6× 提速），别在每个 sample 里重建。

**平台限制**

- HarmonyOS 7 起「沉浸光感」只在**弹窗类组件**与 **Navigation 标题栏 / 底部 TabBar** 内生效，
  且需要在 `module.json5` 里打开应用级开关；把材质挂在普通容器上是看不到效果的。
- 页面里别用 `console`（服务卡片的打包会报错），统一走 `Logger`。
